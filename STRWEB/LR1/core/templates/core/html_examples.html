Теги html, head, title, base, meta, link, style, script, noscript и body показаны здесь как листинг, потому что этот шаблон наследует уже готовую структуру из base.html.

video с атрибутом src

В этом варианте путь к единственному видеофайлу задаётся непосредственно через атрибут src элемента video.

Здесь используются: src, controls, autoplay, muted, loop, preload, poster, width.

video с элементом source

Во втором варианте источник задаётся вложенным элементом source. Этот способ позволяет указать несколько форматов видео.

Пример нескольких source

<video controls>
    <source src="house-tour.webm" type="video/webm">
    <source src="house-tour.mp4" type="video/mp4">

    Ваш браузер не поддерживает video.
</video>

Браузер последовательно проверяет source и выбирает первый формат, который способен воспроизвести.

track — субтитры

<track
    kind="subtitles"
    src="subtitles-ru.vtt"
    srclang="ru"
    label="Русский"
    default
>

track не содержит ещё одно видео. Он подключает текстовую дорожку: например субтитры, подписи или главы.

Атрибуты track из презентации: kind, src, srclang, label, default.

Атрибуты video

Атрибуты из презентации: autoplay, preload, controls, loop, poster, height, width, muted, src.

Возможные значения preload: none, metadata, auto.

audio с атрибутом src

audio с source

Для audio используются те же основные медиа-атрибуты: autoplay, preload, controls, loop, muted, src.

#   — создаёт id
.   — создаёт class
[]  — создаёт атрибуты
>   — переход на уровень ниже
+   — соседний элемент
^   — переход на уровень выше
*   — умножение элементов
$   — счётчик
$$  — двухзначный счётчик
{}  — текстовое содержимое
