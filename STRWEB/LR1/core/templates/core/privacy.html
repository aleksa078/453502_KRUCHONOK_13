Политика конфиденциальности

Какие данные обрабатываются

Сайт homeFULL может обрабатывать имя пользователя, адрес электронной почты, номер телефона, данные профиля и информацию, указанную пользователем в формах сайта.

Цели обработки

  • регистрация и авторизация пользователей;
  • обработка обращений;
  • сопровождение сделок с недвижимостью;
  • публикация отзывов после модерации.

Хранение данных

Данные учебного проекта используются только для демонстрации работы информационной системы.
